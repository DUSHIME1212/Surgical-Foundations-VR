# Surgical Foundations VR — Project Structure & Conventions

Everything we own lives in `Assets/_Project/` (the underscore sorts it first). Third-party and template content (`VRTemplateAssets`, `Samples`, `XR`, `XRI`, `TextMesh Pro`) stays where Package Manager and the template put it. Personal experiments go in `Assets/_Sandbox/` (not referenced by builds).

```
Assets/_Project/
├── Art/
│   ├── Materials/<Category>/   M_<Name>.mat — generated by MaterialLibrary (URP Lit/Unlit)
│   ├── Models/<Category>/      real FBX files go here when they replace placeholders
│   ├── Shaders/                20 SF shaders + Include/ (see Docs/Shaders.md)
│   ├── Textures/  VFX/
├── Animation/  Characters/ Hands/ Instruments/ Controllers/
├── Audio/
│   ├── Ambience/               AMB_*_Loop.wav   (Vorbis, compressed in memory)
│   ├── SFX/UI|Feedback|Instruments|Environment/   SFX_<GROUP>_<Name>.wav (ADPCM, decompress on load)
│   └── Voice/                  VO_<Stage>_<Line>.wav (TTS placeholders until recorded VO)
├── Data/
│   ├── Audio/SoundBank.asset   every SoundId → clip, volume, 2D/3D, subtitle
│   └── UI/UITheme.asset, TMP_Icons.asset   design tokens sampled from Design.pdf
├── Imports/                    third-party models as downloaded (see Docs/ThirdPartyAssets.md)
├── Lighting/
│   ├── LightingSettings/       LS_<Scene>.lighting (GPU lightmapper, Baked Indirect)
│   └── VolumeProfiles/         VP_Theatre / VP_Lobby / VP_Lab (neutral tonemapping + grading)
├── Prefabs/
│   ├── Environment/ Equipment/ Instruments/ PPE/ Anatomy/ TrainingProps/ Characters/   41 asset-list items
│   └── UI/Screens (16 prototype screens)  UI/HUD (HUD, subtitles, monitor overlays)
├── Scenes/
│   ├── Core/00_Bootstrap        persistent: XR rig, services, pause, subtitles
│   ├── Frontend/01_Lobby 02_SkillsLab
│   ├── Theatre/10_OR_Base + 11–14 stage scenes (loaded additively)
│   └── Tools/90_ReplayViewer    separate desktop/WebGL build
├── Scripts/
│   ├── Runtime/  (SurgicalFoundations.Runtime.asmdef)  Core, Scenario, Audio, Lighting, Interaction, UI, Placeholders
│   └── Editor/   (SurgicalFoundations.Editor.asmdef)   Builders/, Tools/
├── Settings/  UI/Sprites  UI/Icons  UI/Fonts
```

## Naming
| Kind | Pattern | Example |
|---|---|---|
| Prefab (asset list item) | `<CAT>_<Name>` | `EQ_LapTower`, `INST_MarylandDissector`, `ANA_AbdominalCavity` |
| UI screen | `UI_<NN>_<Name>` (NN = prototype screen) | `UI_06_Sterility` |
| Material | `M_<Name>` | `M_Instrument_Insulation` |
| Sound | `<SFX_GROUP|AMB|VO>_<Name>[_Loop]` → `SoundId.<GROUP>_<Name>` | `SFX_INST_ClipFire.wav` → `SoundId.INST_ClipFire` |
| Scene | `NN_Name` | `13_Stage_Operate` |

Categories: `ENV` environment, `EQ` equipment, `INST` instrument, `PPE`, `ANA` anatomy, `PROP` training prop, `CHR` character.

## Replacing a placeholder with the real model
Every placeholder prefab is `Root` (gameplay: colliders, XR grab, sounds, pivots) → `Visual` (primitives only).
1. Import the FBX into `Art/Models/<Category>/`.
2. Open the prefab, delete the children of `Visual`, drop the model under `Visual`.
3. Keep named transforms the code relies on: `Pivot_Tip`, `Pivot_Port`, `Attach`, `Jaw_Upper`/`Jaw_Lower` (under `JawHinge`), `CameraSocket`, `WaterSocket_*`, `Socket_*`, `TableTop`, `LapTower_Screen`, `Umbilicus`, `Layer_*`.
4. Untick **Is Placeholder** on `PlaceholderInfo`. `Surgical Foundations ▸ Tools ▸ Placeholder Report` lists what's left.

> ⚠️ The builders overwrite generated assets. Once a prefab has real art, stop regenerating it (remove its call from `PlaceholderFactory.BuildAll`).

## Builders (menu: Surgical Foundations)
| Menu | What it does |
|---|---|
| Build Everything | 0–4 below in order |
| Build ▸ 0 · Rendering Settings | URP: per-pixel additional lights, spot shadows, reflection probe blending + box projection, linear intensity, colour temperature |
| Build ▸ 1b · Imported Model Materials | texture settings + PBR materials for `Imports/` (see `Docs/ThirdPartyAssets.md`) |
| Build ▸ 1 · Placeholder Models | 41 prefabs + materials; uses imported models where available (nurse, anaesthetist) + imported props |
| Build ▸ 2 · Sound Bank | maps clips to `SoundId`; keeps hand-tuned values |
| Build ▸ 3 · UI Screens | 16 screens + HUD, subtitles, monitor overlays |
| Build ▸ 4 · Scenes | 9 scenes + build settings (built additively; your open scene is untouched) |
| Build ▸ 5 · Bake Lighting | bakes Lobby, SkillsLab, OR_Base, ReplayViewer |
| Tools ▸ Render UI Previews | PNGs of every screen → `Docs/UI Previews` |

## Lighting model
- Rooms fully baked: area lights over the ceiling panels, emissive panels, AO, 3 bounces, non-directional lightmaps (Quest memory).
- Surgical heads: **Mixed** spots in Baked Indirect mode → real-time specular on steel + one soft shadow over the field.
- Dense light probes around the table so instruments, hands and characters get bounce light; stage-scene props light from OR_Base probes.
- Box-projected reflection probes (room + high-priority table probe for instrument reflections).
- Post: neutral tonemapping + grading on PC; off on Quest by default (`PlatformPostProcessing`).
- Laparoscope: separate camera + scope light rendering to a RenderTexture on the tower monitor (`LaparoscopeFeed`; resolution/refresh are the perf levers).

## Audio
`AudioManager` (in Bootstrap) plays everything by `SoundId`. Categories UI / Feedback / SFX / Ambience / Voice with their own volume; ambience ducks under voice; voice lines raise subtitles. All sounds are original placeholders (synthesised, TTS voice) — replace clips in place, keeping file names.

## Running
Press Play in **any** project scene: `AppBootstrap` pulls in `00_Bootstrap` (and `10_OR_Base` for a stage). Esc (desk) or the left-controller menu button pauses.
