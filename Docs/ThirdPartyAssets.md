## Housekeeping
- `monitor-computer-realistic-computer-monitor/` also contains duplicate copies of the doctor, nurse, heart-lung machine, microscope and surgery tools (and their textures) — ~half of the 153 MB. Only `Monitor.fbx` is used from that folder; the duplicates can be deleted once confirmed.
- `Surgery Tools.fbx` is 165k triangles — over a third of the 400k Quest scene budget. It's only placed in the skills lab. Decimate (or get a lower-poly version) before using it in the theatre.
- Texture import settings, materials (`Art/Materials/Imported`) and packed MetallicSmoothness maps (`Art/Textures/Imported`) are generated by **Surgical Foundations ▸ Build ▸ 1b · Imported Model Materials**.
- `.glb` files need **glTFast** (`com.unity.cloud.gltfast`, in `Packages/manifest.json`).
- `Patient.fbx` and `Hospital equi/Untitled.fbx` have **Read/Write** enabled so the builders can measure and split their meshes. The shipped meshes are the generated ones (`Art/Meshes/`), so this costs no runtime memory.
- The ward-room FBX ships without textures. Its furniture uses generated tileable textures (`Art/Textures/Hospital`, `HospitalTextures.cs`) assigned per part by rules in `PlaceholderFactory.Hospital.cs`.
